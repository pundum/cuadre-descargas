# Descargar Cuadre

Ventas, inventario y cuadre de caja para restaurantes. Funciona sin internet.

**Página de descarga:** https://pundum.github.io/cuadre-descargas/

Los instaladores están en [Releases](https://github.com/pundum/cuadre-descargas/releases/latest):

- `Cuadre-Android.apk`: tablets y celulares Android (la mayoría).
- `Cuadre-Android-universal.apk`: tablets Android más antiguas.
- `Cuadre-Windows.exe`: computadores con Windows 10 u 11.
